# Monetization Plan

## Open Source Core

- MIT CLI.
- Local diff scanning.
- Built-in rules.
- SARIF output.
- GitHub Action wrapper.

## Hosted SaaS

- Team dashboards.
- Scan history and trends.
- Slack/Discord alerts.
- Private rule packs.
- Organization policies.
- Compliance exports.

## Enterprise

- Self-hosted Laravel backend.
- SSO and RBAC.
- Audit logs.
- Private LLM/provider configuration.
- Custom security rules and support.

The free product must stay useful without an account. Monetization should come from collaboration, history, governance, and enterprise controls.
