# PatchProof v0.3.0

PatchProof v0.3.0 expands the product from a local diff scanner into a hosted review workflow with remediation guidance and optional AI enrichment.

## Highlights

- Added hosted scan views for projects, scans, usage logs, and findings
- Added deterministic remediation guidance for each finding
- Added optional AI enrichment for remediation suggestions
- Added backend and frontend support for storing and displaying scan history
- Expanded OWASP coverage across:
  - A01 Broken Access Control
  - A02 Cryptographic Failures
  - A03 Injection
  - A04 Insecure Design
  - A05 Security Misconfiguration
  - A06 Vulnerable and Outdated Components
  - A07 Identification and Authentication Failures
  - A08 Software and Data Integrity Failures
  - A09 Security Logging and Monitoring Failures
  - A10 SSRF
